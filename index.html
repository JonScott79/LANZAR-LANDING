THREADLINE

Communication Intelligence & Timeline Analysis

PREVIEW ↗

The Mission: A local-first communication analysis platform built for professionals (investigators, attorneys, researchers) that transforms fragmented conversational data into structured, chronological timelines.

Where We Are: Core local SQLite database architecture with WAL mode and FTS5 full-text search is operational. Parsers for SMS Backup & Restore XML and HTML conversation exports are built.

What's Next: Expanding multi-format message ingestion (Messenger, WhatsApp, Signal, and email formats), polishing the interactive timeline UI, and readying public testing.
